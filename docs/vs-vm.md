# 为什么不用虚拟机（以及和其它远程方案的对比）

先把结论说在前面：

> **如果目标只是"让一个人随时能用上这个桌面应用"，虚拟机付出的成本远大于收益。**
> 虚拟机真正值得用的场景是：需要系统级隔离、多人多租户、需要跑不同内核/驱动、需要快照回滚做实验。

---

## 一、和"虚拟机里跑桌面"的对比

| 维度 | 虚拟机方案 | 本项目（无头 X 会话） |
| --- | --- | --- |
| 常开主机 | 需要一台性能足够的机器，且不能休眠 | 复用本来 7×24 的 NAS |
| 内存 | 整机 4–8 GB 起 | 约 300–800 MB（应用 + X + VNC） |
| 磁盘 | 系统镜像 20 GB+，随快照膨胀 | 只有应用与用户数据，通常 < 2 GB |
| 启动 | 宿主开机 → 虚拟机自启 → 进桌面 → 拉应用 | systemd 直接拉起，秒级 |
| GPU | 部分桌面需要 3D 加速，虚拟化下易黑屏 | 不需要，纯软件渲染 |
| 分辨率 | 固定虚拟显示器，改分辨率要重启 X | `xrandr` 运行期调整，跟随窗口 |
| 剪贴板 | 依赖 Guest Additions / VMware Tools | 自建桥，UTF-8 + 图片 |
| 升级应用 | 进虚拟机操作，或重装镜像 | 换 deb + `systemctl restart` |
| 备份 | 镜像/快照，几十 GB | 打包用户目录，几百 MB |
| 迁移 | 镜像与虚拟化平台绑定 | 脚本 + unit 文件，重放即可 |
| 隔离性 | **强**：整机隔离、可快照回滚 | **中**：与宿主同一用户会话 |
| 图形性能 | 中（有 3D 加速时更好） | 偏弱（文本/网页够用） |
| 维护复杂度 | 高（系统更新、驱动、时间同步） | 低（无系统层） |

### 成本感受（按家庭场景估算）

- 一台常年开机的迷你主机：待机 8–15 W，一年约 70–130 度电；
- 一块 20 GB 的虚拟机镜像 + 快照：占掉 SSD 一大块，且备份很慢；
- 真正的时间成本在**维护**：系统更新失败、显卡驱动、远程协议掉线，每次都要进虚拟机"修"。

本项目把这些都省掉，代价是**放弃整机隔离**（见下）。

### 什么时候该选虚拟机

- 需要跑不受信任的软件，担心影响宿主；
- 需要给多个人各自一个独立桌面；
- 需要不同发行版/内核做兼容性测试；
- 需要"关机前拍快照，出问题一键回滚"。

这些需求本项目都不满足，也不打算满足。

## 二、和向日葵 / ToDesk / RDP 的对比

| 维度 | 商业远控 | 本项目 |
| --- | --- | --- |
| 被控端 | 必须有一台开着的 Windows/macOS | Linux 无头即可 |
| 授权 | 免费版限速/限设备，商用需付费 | 无订阅 |
| 剪贴板 | 厂商实现，中文/图片时好时坏 | 自建，可控可调 |
| 分辨率 | 跟随被控端 | 跟随客户端窗口 |
| 隐私 | 画面经厂商中继（多数情况） | 直连自己的服务器 |
| 多端 | 每台设备装客户端 | 浏览器零安装 |
| 一致性 | 依赖厂商版本 | 代码即配置 |

商业远控的优势是"开箱即用、穿透能力强"。如果你的网络环境无法做端口映射或反代，它们更省事；本项目需要你至少有一条能到达 NAS 的链路（公网端口、Tailscale、Cloudflare Tunnel 等）。

## 三、和"直接开 VNC"的对比

| | 裸 VNC | 本项目 |
| --- | --- | --- |
| 端口 | 5900 直接暴露，口令弱 | 只开 443，TLS + Basic |
| 剪贴板 | Latin-1，中文必坏 | UTF-8 + 图片 |
| 分辨率 | 手动 | 跟随窗口 |
| 客户端 | 每台装 | 浏览器 / 可选客户端 |
| 会话保持 | 断线即断 | 服务端常驻，重连即回 |

## 四、资源实测（参考值）

在一台 N100 / 16 GB 的 NAS 上：

| 项目 | 占用 |
| --- | --- |
| Xvfb + openbox + tint2 | 60–120 MB |
| 应用本体（空载） | 250–450 MB |
| x11vnc + websockify | 30–60 MB |
| clipbridge | 20 MB |
| 合计 | **约 400–650 MB** |
| 空闲 CPU | < 3% |
| 一路 1080p 画面（局域网） | 2–6 Mbps；公网视变化量而定 |

对比之下，一个装了桌面环境的虚拟机空载通常就要 1.2–2 GB。

## 五、怎么选（决策表）

| 你的情况 | 建议 |
| --- | --- |
| 家里有 NAS，想随时随地在任何设备上接着用 | **本项目** |
| 只有一台常开的 Windows，不想折腾 | 商业远控 |
| 需要给家人/同事各自独立桌面 | 虚拟机 / 多用户方案 |
| 需要跑不可信程序 | 虚拟机 + 快照 |
| 内网只有 IPv6 或无法映射端口 | 本项目 + Tailscale/Cloudflare Tunnel |
| 对画质/帧率有要求（视频剪辑、3D） | 本地机器，不要远程 |

---

## 六、一句话总结

虚拟机买的是**隔离**，本项目买的是**可达性与一致性**。
对"一个人、一个应用、随时接着用"这个目标，后者的性价比高一个数量级。
